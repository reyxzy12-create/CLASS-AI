# CLASS-AI

CLASS-AI adalah asisten AI berbasis web yang dirancang untuk membantu pengguna mendapatkan informasi, menjawab pertanyaan, belajar, dan menyelesaikan berbagai kebutuhan melalui percakapan dengan AI.

✨ Fitur

- 💬 Chat AI interaktif.
- ⚡ Respons AI dengan streaming.
- 📝 Format jawaban Markdown yang rapi.
- 📚 Mendukung berbagai pertanyaan dan topik.
- 🗂️ Riwayat percakapan.
- 📱 Tampilan web yang dapat digunakan di perangkat mobile maupun desktop.

🛠️ Teknologi

- HTML
- CSS
- JavaScript
- Groq API
- Vercel
- GitHub

🚀 Deployment

Project ini dapat dijalankan dan di-deploy menggunakan Vercel.

1. Upload project ke GitHub.
2. Hubungkan repository GitHub ke Vercel.
3. Tambahkan Environment Variable berikut:

Key| Value
"GROQ_API_KEY"| API key Groq milikmu
"GROQ_MODEL"| Model Groq yang ingin digunakan (opsional)

4. Jalankan deployment.
5. Buka URL website yang diberikan Vercel.

🔐 Keamanan

Jangan pernah membagikan API key secara publik atau menuliskannya langsung di kode frontend. Simpan API key melalui Environment Variables di Vercel.
